
# Sentence Analyzer and Prime Checker

## Project Description
A beginner-friendly Python project that analyzes
sentences and checks prime numbers.

## Features
- Counts words in a sentence.
- Finds the longest word.
- Reverses a sentence.
- Checks whether a number is prime.

## Technologies Used
- Python 3

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run this command:

python sentence_analyzer.py

5. Enter a sentence and a number.
